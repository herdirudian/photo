Metode Cepat Keyboard Windows

Jalur folder sudah tersalin di clipboard komputer. Cukup ikuti 3 langkah praktis ini:

1 Buka jendela dialog Run
Win + R
2 Tempel jalur folder yang tersalin
Ctrl + V
3 Buka folder langsung di File Explorer
Enter

Opsi: Buka Otomatis 1-Klik

Agar tombol "Buka di File Explorer" langsung membuka folder tanpa dialog Run, pasang konfigurasi berikut satu kali di komputer counter:

Pasang Konfigurasi 1-Klik (.reg) Unduh & jalankan berkas registri ini satu kali (pilih Yes saat konfirmasi Windows).
