Sumber Folder Foto (Network Share / SMB)

Atur alamat IP dan folder sharing tempat kamera wahana mengunggah foto.

CIFS / Samba 3.0
//
Contoh: IP server sharing foto (misal: 192.168.100.93).
Default: 445 (Samba).
Nama share folder di Windows / Linux (misal: photo).
Biarkan kosong jika semua subfolder wahana ada di root share.
Path default ini terhubung langsung ke kontainer Docker sistem foto.
📋

Perintah Mount di Server Ubuntu

Jika server belum me-mount folder CIFS secara otomatis, Anda cukup menyalin perintah di bawah ini ke terminal server:

sudo mount -t cifs //192.168.100.93/photo /opt/SistemPhoto/data/raw -o username=USER_SHARE,file_mode=0777,dir_mode=0777,iocharset=utf8
